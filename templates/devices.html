QURILMA YOKI KOMPYUTERNI BOSHQARISH

Qurilma, Kompyuter ID va IP sozlamalari

Kompyuter (Tarozi / E-navbat parkovka) yoki APK terminal nomini, Kompyuter ID / IMEI belgisini, IP manzilini yoki ruxsat holatini o‘zgartiring. Tasdiqlangan kompyuter va APK qayta ruxsat so‘ramaydi.
YANGI KOMPYUTER YOKI TERMINAL QO‘SHISH

Kompyuter (IP / ID) yoki APK (IMEI) qo‘shish

Tarozi va E-navbat parkovka kompyuterlari uchun kompyuterning IP manzilini yoki maxsus ID belgisini (yoki KPP telefonlari uchun IMEI kodini) kiriting. Qurilma darhol tasdiqlangan holatda ro‘yxatga olinadi.
